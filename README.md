# NEON VISUALS

**A visual enhancement mod for Minecraft Fabric.**

NEON VISUALS adds visual effects, HUD enhancements, animations and extra features to Minecraft.

## Information

- **Version:** Beta Pre-release 1
- **Minecraft:** 1.21.4
- **Mod Loader:** Fabric
- **Java:** 21
- **Required:** Fabric API

## Installation

1. Install Fabric Loader for Minecraft 1.21.4.
2. Install Fabric API.
3. Download NEON VISUALS from the [Releases](https://github.com/timenerall/NEON-VISUALS/releases) page.
4. Put the downloaded `.jar` file into your Minecraft `mods` folder.
5. Launch Minecraft using the Fabric profile.

## Beta Notice

NEON VISUALS is currently in beta. You may encounter bugs, unfinished features or unexpected behavior.

Please report bugs through GitHub Issues.
